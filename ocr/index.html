如何让图片文字识别准确率提升至 99% 以上？

OCR 模型的识别精度与图像质量密切相关，掌握以下技巧能大幅减少校对时间：

1. 尽量裁剪无关边缘背景

如果在识别书籍拍照或手机截屏时周围有大量阴影、手指或复杂的杂乱背景，建议先用手机相册裁剪掉边缘空白。这能帮助神经网络更聚焦于正文区域，显著提高识别速度与排版完整度。

2. 保证光照均匀、避免过暗或反光

使用手机拍照纸质文件时，尽量避免台灯单一角度照射产生的严重反光或手持设备投下的浓重阴影。光照越均匀、文字与纸张的对比度越强，检测模型对字形边缘的定位就越精准。

3. 保持文字水平或正向朝上

虽然 PP-OCRv6 具备一定的角度检测容错能力，但当文本发生 90° 旋转或大角度倾斜时，可能会增加字符形变的误判率。在上传前先将图片扶正，准确率将达到最佳。

4. 表格单据优先导出为 Excel 进行整理

在识别带框线的财务发票、对账单或表格截屏时，直接点击右上角“导出 Excel”，系统会将按行识别出的文本数据规整填入单元格，避免了手动逐项复制粘贴排版的繁琐流程。

我导入的文件真的不会被任何第三方收集或偷看吗？

多页长篇 PDF 怎么识别？有页数限制吗？

没有强制页数限制！上传 PDF 后，左侧会激活“PDF 页面控制”面板。您可以点击“上一页/下一页”选择性识别特定页面，也可以点击“一键批量识别所有页面”，系统将自动依次把每一页渲染为高清图像并在本地后台线程中完成识别，最后将全部页面的文字合并供您一键复制或导出。

识别速度慢或者浏览器卡顿怎么办？

本工具的推理运算由独立 Web Worker 后台多线程驱动，通常不会卡死主界面。但识别速度直接取决于当前设备的 CPU 性能。若处理上千万像素的高清大图较慢，可先通过本站的“批量图片转换压缩”工具将原图长宽等比缩减至 1500~2000px，这能在保证识别准确率的同时让处理速度提升 3~5 倍。

支持手写体或古代书法字体识别吗？

本工具搭载的 PP-OCRv6 针对印刷体、屏幕截图、公文扫描件、招牌横幅有极致的准确率。对于字迹工整清晰的硬笔手写体（如学生作业、会议笔记）具备良好的识别效果；但对于极度连笔、草书或艺术变形字，建议以识别后的人工校对为准。
