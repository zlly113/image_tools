关于超级工具箱 Pro

打造纯本地、零上传的现代生产力工具矩阵

我们相信，每一个用户对自己的个人数据和文档都拥有神圣不可侵犯的隐私权。我们拒绝将用户的身份证照、合同发票、私人相片上传到不可控的云端服务器，而是借助前沿的 Web 算力，让一切复杂运算直接在您的浏览器本地极速完成。

一、创立初衷与愿景

市面上绝大多数传统的在线格式转换、图片抠图或 PDF 工具，往往要求用户先将整份私密文件“上传”至远程云端服务器进行排队计算，随后再下载回本地。这不仅带来了极大的隐私泄露风险（敏感证件、合同文件留存云端），还严重受限于上下行网络带宽，遇到网络拥堵甚至频繁上传失败。

超级工具箱 Pro 应运而生。我们的核心使命是：彻底消除数据上传中间环节。依托现代 WebAssembly、Canvas 2D 硬件加速与 Web Workers 异步管线，我们把原本需要笨重桌面软件才能处理的专业级任务，全部轻量化移植进网页，打造开箱即用、无广告遮挡、断网也能秒级工作的现代高效工具箱。

二、核心产品功能矩阵

智能证件照制作与纯色去底

毫秒级连通域分析算法，支持白底、蓝底、红底一键替换，自定义透明背景，完美适配各类报考认证照要求。

支持 PDF 极速合并、高保真单页拆分、提取页面为多格式图片、批量加盖防伪水印及一键彻底脱敏元数据。

美化二维码与防封短链

支持自定义码元几何造型、渐变色彩与中间 Logo 嵌入，并提供毫秒级高并发短链接跳转生成服务。

About Super Toolbox Pro

Pure Client-Side, Zero-Upload Modern Productivity Tools

We believe that user data privacy is fundamental and non-negotiable. Rather than sending your photos, invoices, and sensitive documents to remote cloud servers, we harness cutting-edge WebAssembly technology to perform all complex processing directly inside your browser.

1. Our Mission & Vision

Most conventional web converters require users to upload confidential files to third-party cloud backends. This introduces significant data leak vulnerabilities and slow network upload bottlenecks.

Super Toolbox Pro eliminates the middleman. By utilizing WebAssembly (WASM), Canvas 2D pipelines, and Web Workers, we deliver desktop-grade performance directly inside the browser—with zero file uploads and 100% offline capability.

2. Key Capabilities

Smart ID Photo & Background Eraser

Interactive solid color background removal with seamless white/blue/red background substitution.

Offline Deep Learning OCR

Powered by PaddleOCR (PP-OCRv6) and ONNX Runtime Web. Fully offline text recognition and multi-page PDF export to Word & Excel.

Client-Side PDF Toolkit

High-speed PDF merging, single-page extraction, batch image conversion, watermarking, and privacy metadata stripping.

Artistic QR Codes & Short Links

Custom visual QR codes with corner and dot customization, coupled with fast URL shortening services.
