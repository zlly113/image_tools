常见问题解答 (FAQ)

关于 PDF 拆分、转图清晰度与安全防伪的精选问答：

上传的商业合同、标书或财务凭证真的不会被泄露吗？

绝对不会。超级工具箱所有功能均由现代浏览器 WebAssembly 与本地 JavaScript 二进制内存流驱动。整个处理过程无需任何服务端接口，您可以按 F12 打开开发者工具的 Network 面板进行全程监控，期间不会发起任何文件上传请求。即使拔掉网线，所有拆分、合并与转图功能依然能离线流畅工作。

怎么把特定几页（例如第 1、3、5 到 8 页）单独提取出来？

进入“页面编排与管理”的“页面拆分与提取”选项，上传 PDF 后在输入框中填入页码规则，如“1, 3, 5-8”，然后点击“提取选中页面”，系统会在瞬间提取这几个页面并合并为一个全新的紧凑 PDF 文件供您直接下载。

添加防伪水印后，文字可以被轻松删除或去除吗？

本工具的水印算法直接将平铺文字以向量或图层形式深深烧录进 PDF 的底层内容流（Content Stream）中，覆盖范围紧密均匀。接收者即使打印或拍照，水印文字依然清晰可辨，能有效威慑恶意二次盗用或拍照外泄。

什么是“敏感元数据脱敏”？有什么实际作用？

常规生成的 PDF 内部通常潜藏着制作者电脑用户名、编辑软件版本（如 Word/InDesign）、创建修改时间甚至内部文件路径。在向客户发送商业方案或政务公开文档前，使用“敏感元数据一键脱敏”能彻底擦除这些隐性标识，避免无意间暴露内部技术指纹与隐私信息。
