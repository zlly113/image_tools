# 超级工具箱 Pro (v2.0.0)

超级工具箱 Pro 是一款完全运行在浏览器本地的多功能一体化在线工具平台。项目采用纯静态前端技术栈，搭载本地 WebAssembly 神经网络推理引擎和图像处理管线，**无需上传任何文件到服务器，100% 保护用户隐私**。

---

## 🚀 核心功能特性

### 1. 📷 智能证件照制作 (`bg-remover`)
- **智能抠图**：基于 Canvas 像素提取和连通域算法（FloodFill），提供边缘智能去底与强制颜色去除双模式。
- **一键替换背景**：内置 white、blue、red 以及自定义图片背景替换，快速生成标准证件照。
- **实时调优**：支持边缘容差值的交互式滑动微调。

### 2. 🎞️ 高级相片排版与胶片水印 (`collage`)
- **多图排版**：支持垂直长图拼合、水平横图拼合及智能网格排列，支持拖拽（Drag & Drop）自由重排或删除图片。
- **徕卡风 EXIF 水印**：自动读取照片的 EXIF 拍摄参数（相机型号、光圈、快门、ISO、焦距），在照片底部渲染极具质感的胶片边框水印。

### 3. 🔄 批量格式与尺寸转换 (`converter`)
- **异步批处理**：多文件异步读取，在客户端内存中快速进行图片尺寸修改、等比例缩放。
- **无损压缩**：支持导出为 JPG、PNG、WebP，提供 JPG/WebP 实时画质控制。
- **一键打包**：集成 JSZip 库，转换完成后自动打包为 `.zip` 压缩包下载。

### 4. 🎨 电影级滤镜与画质修复 (`enhancer`)
- **画质微调**：实时调整亮度、对比度、饱和度。
- **超清修复**：内置 3x3 卷积矩阵（Convolution Matrix Kernel）图像锐化算法，一键高清化模糊图像。
- **艺术滤镜**：预设复古胶片、经典黑白、冷调赛博、暖秋时光等多款精美滤镜。

### 5. 🔍 智能文字识别 & PDF 提取 (`ocr`)
- **本地离线推理**：基于 PaddleOCR (PP-OCRv6) 深度学习模型，使用 ONNX Runtime Web (WASM) 引擎在浏览器本地完成文字检测与识别，毫秒级响应。
- **PDF 多页提取**：集成 PDF.js，支持 PDF 逐页高精度识别或一键批量提取所有页面文本。
- **智能排版与导出**：自动进行物理段落及表格列对齐优化，支持一键复制，或导出为 TXT、标准 Word (`.docx`)、对齐 Excel 表格 (`.xlsx`)。

### 6. 🔗 链接与二维码工具箱 (`link-tools`)
- **美化二维码生成**：可自定义前景色、背景色（支持透明）、码元样式（圆角/流线/点状）、定位角样式，支持中心嵌入 Logo 及自动提升容错级别。
- **多通道本地解码**：优先使用浏览器原生 AI 硬件条码检测器，降级使用自研 3-Pass 灰度与对比度增强通道算法（最大/最小 RGB 提取）+ jsQR 引擎，大幅提升彩色、艺术二维码的识别率。
- **短链接生成与历史**：对接 `is.gd` API，支持自定义别名后缀及自定义接口配置。内置防 XSS 安全转义，本地存储最近 10 条生成历史，并支持与二维码工具箱一键联动。

## 🛠️ 技术架构与开源依赖

- **前端框架**：HTML5 + Tailwind CSS (v3 本地版 Play CDN) + Vanilla JS (ES6+)
- **神经网络引擎**：ONNX Runtime Web (`ort.js` v1.24.3) + PaddleOCR WASM Worker
- **文档生成库**：`docx.js` + `xlsx.js` (SheetJS) + `JSZip`
- **其他辅助库**：`pdf.js` (PDF 渲染) + `exif.js` (读取相机参数) + `qr-code-styling` (二维码美化)

## 📦 部署与本地运行指南

> [!IMPORTANT]
> **本地运行限制说明**：
> 本项目涉及 **Web Worker**、**ES Modules (importmap)** 以及大量本地静态资源文件（如 ONNX 权重 `det.tar`、`rec.tar`）的 `fetch` 请求。受限于现代浏览器的安全策略，**直接双击 `index.html`（即 `file://` 协议）无法正常运行 OCR 模块**。

### 本地快速启动
您需要使用任何静态 Web 服务器托管该项目目录。以下是常用的本地启动方式：

#### 方法 A：使用 Node.js (推荐)
如果在本地安装了 Node.js，可以在项目根目录下执行：
```bash
# 全局安装 http-server (如已安装可跳过)
npm install -g http-server

# 在当前目录启动服务器
http-server -p 8080
```
然后在浏览器中访问 `http://localhost:8080` 即可。

#### 方法 B：使用 Python
如果安装了 Python，可以在项目根目录下运行：
```bash
# Python 3
python -m http.server 8080
```
然后在浏览器中访问 `http://localhost:8080`。

### 生产部署
将项目文件夹下的所有文件（包括 `index.html`、`opencv-esm-wrapper.js`、`robots.txt`、`sitemap.xml` 以及整个 `models` 目录）上传至您的 Nginx、Apache 或云静态托管服务（如 GitHub Pages、Vercel、Netlify）。

> [!NOTE]
> **绝对路径注意事项**：
> 静态资源及模型权重文件的加载路径硬编码在域名根目录（如 `/models/...`）。部署时请确保项目托管在**网站根目录**。如果需要部署在二级子目录下，请修改 `index.html` 中的资源引用路径。
