## 1. 移动端 PWA 离线体验强化实施总览

由于超级工具箱 Pro 采用 **100% 浏览器客户端本地推理（纯前端 WASM + Canvas + Web Worker）** 架构，与 PWA（Progressive Web App）是天然的绝配。本次改造完成了以下强化：

### 1.1 图标全规格补齐与 manifest.json 规范化
* **图标矩阵补齐**：自动生成了符合 W3C 标准的 `icons/icon-192.png`、`icons/icon-512.png`、`icons/apple-touch-icon.png` 与矢量 `icons/icon.svg`。
* **应用快捷方式 (Shortcuts)**：移动端长按 App 图标时，可直接呼出 **「离线文字识别」**、**「证件照换底色」**、**「PDF工具箱」**、**「二维码工具」** 四大核心功能并秒级直达。
* **全站各独立落地页支持**：主站及 6 个独立落地页均已补充完整 PWA 沉浸式 Meta（状态栏自适应、添加到主屏幕标题等）。

### 1.2 Service Worker 缓存与离线智能路由 (`sw.js`)
* **预缓存清单升级**：将全站所有独立落地页、核心 JS 模块、本地离线字体与图标全部纳入 App Shell 预缓存。
* **离线智能降级策略**：若用户手机断网后直接打开某个子落地页（如 `/ocr/`），Service Worker 能够优先匹配本地已缓存的该落地页，未缓存时才降级回退至首页，确保断网也能完整使用。

### 1.3 沉浸式交互模块 (`js/pwa.js`)
* **离线状态指示浮条**：用户网络中断时，页面顶部自动滑出翡翠绿横条：  
  `已进入离线模式 · 本地所有工具与 AI 引擎均可离线运行，隐私绝对安全`  
  断网瞬间给予用户强烈的安全感与技术信任。
* **一键安装提示**：在支持 PWA 的移动端/桌面浏览器（Chrome/Edge/Android）上，自动展示轻量卡片提示用户一键“安装到主屏幕”，关闭后 7 天内不再打扰。

## 2. 百度搜索资源平台（百度站长）收录与提交实战

百度在国内搜索市场仍占有极高权重，做好百度站长提交是新站冷启动的关键一步。

### 2.1 站点添加与属性验证
1. 打开 [百度搜索资源平台](https://ziyuan.baidu.com/) 并登录百度账号。
2. 进入 **「用户中心」 ➡️ 「站点管理」 ➡️ 「添加网站」**：
   * 协议头务必选择：`https://`
   * 填写主域名：`www.hhdzai.top`
   * 领域类型选择：`IT科技` 或 `工具/软件`
3. **验证网站所有权**（推荐以下两种之一）：
   * **方式 A：文件验证（最快）**：下载百度提供的 `baidu_verify_xxx.html` 文件，上传到腾讯云服务器 `/www/wwwroot/hhdzai.top/` 目录下，确保通过浏览器能直接打开 `https://www.hhdzai.top/baidu_verify_xxx.html`，然后点击百度后台的“完成验证”。
   * **方式 B：HTML 标签验证**：将百度提供的一串 `<meta name="baidu-site-verification" content="xxx" />` 复制并添加到 `index.html` 的 `<head>` 中。

### 2.2 开启 HTTPS 认证
在百度站长平台左侧菜单找到 **「搜索服务」 ➡️ 「HTTPS业务」 ➡️ 「HTTPS认证」**：
* 提交 `https://www.hhdzai.top` 进行认证。
* 认证通过后，百度搜索结果将全面展示 HTTPS 安全绿锁标识，且优先给予高排序权重。

### 2.3 提交 Sitemap 站点地图
1. 进入 **「资源提交」 ➡️ 「普通收录」 ➡️ 「sitemap」**。
2. 填写 Sitemap 完整地址：  
   `https://www.hhdzai.top/sitemap.xml`
3. 提交频率选择每周或每天。百度蜘蛛通常在 1~3 天内完成首次爬取。

### 2.4 API 主动推送（最快收录通道）
百度提供了准入密钥 API，允许站长每天主动将最新页面直接推送到收录队列，速度远快于被动等待爬虫。
本项目已内置一键推送脚本：[`docs/seo/baidu_push.py`](file:///d:/develop/image_tools/docs/seo/baidu_push.py)。

**使用步骤**：
1. 在百度站长平台 **「普通收录」 ➡️ 「资源提交」 ➡️ 「API提交」** 中，查看您的接口调用地址，复制其中的 `token=xxxxxx`。
2. 在本地或腾讯云服务器上运行：
   ```bash
   python docs/seo/baidu_push.py --token 你的百度Token
   ```
3. 终端将输出推送结果，例如：
   ```text
   [*] 从 sitemap.xml 成功提取 11 个待推送链接。
   [*] 正在向百度推送 11 个核心 URL...
   [+] 百度接口响应成功：
       成功推送条数: 11
       当天剩余可用额度: 2999
   ```

## 3. Google Search Console (GSC) 提交与收录实操

Google 是海外流量与高端技术开发者流量的主要来源，对 SPA 纯静态站和 Schema.org 结构化数据支持极其完善。

### 3.1 资源添加与所有权验证
1. 访问 [Google Search Console](https://search.google.com/search-console) 并使用 Google 账号登录。
2. 点击左上角 **「添加资源」**：
   * 推荐选择 **「网域」(Domain)**：输入 `hhdzai.top`（需在腾讯云 DNSPod 增加一条 TXT 记录，一次性验证所有二级域名与子路径）。
   * 或选择 **「网址前缀」**：输入 `https://www.hhdzai.top/`，下载 Google 验证 HTML 文件上传到服务器根目录完成验证。

### 3.2 提交站点地图
1. 在左侧菜单点击 **「站点地图」(Sitemaps)**。
2. 在“添加新的站点地图”输入框中输入：`sitemap.xml` 并点击提交。
3. 状态显示绿色 **「成功」** 即代表 Google 已成功读取全站页面。

### 3.3 网址审查与优先编入索引
对于 6 个核心工具落地页，无需等待自然抓取，可手动加速索引：
1. 在顶部搜索框输入目标页面（例如 `https://www.hhdzai.top/ocr/`）。
2. 点击 **「测试实际网址」**（Test Live URL）：检查 Googlebot 渲染结果，确认正文和 Schema 提取正常。
3. 点击 **「请求编入索引」**（Request Indexing）。每个页面约在 24~48 小时内完成收录。

### 3.4 富媒体搜索结果（Schema）检验
通过 Google 官方的 [富媒体结果测试工具](https://search.google.com/test/rich-results) 输入你的落地页 URL，确保检测出：
* **WebApplication**（应用名称、评分、免费标识）
* **FAQPage**（搜索结果下方展开问答折叠框）
* **BreadcrumbList**（网站层级面包屑路径）

## 4. 高质量外链建设（Backlinks）与流量冷启动策略

2. **稀土掘金 (juejin.cn)**：
   * **发布专栏**：前端技术 / 架构设计。

3. **知乎精准问题回答 (zhihu.com)**：

### 4.3 开源项目与友链置换（SEO 权重稳固）
1. **GitHub 开源生态**：
   * 在 GitHub 寻找相关的 `awesome-` 仓库提交 PR：

     * `awesome-offline-first`
     * `awesome-tools`
2. **同量级独立博客 / 工具站友链互换**：
