超级工具箱 Pro 是完全免费的吗？

是的！超级工具箱 Pro 目前提供的所有功能（包括高精度 PaddleOCR 文字识别、智能证件照抠图、多图排版拼接、批量图片压缩与格式转换、胶片滤镜画质修复、美化二维码生成与解码等）完全免费向公众开放，即开即用，无需任何付费门槛。

使用本工具箱会上传我的图片、文件或个人数据吗？

绝对不会！ 本项目搭载纯前端 WebAssembly 神经网络推理引擎与 Canvas 像素管线，所有图像识别与处理均100% 运行在您当前设备浏览器的本地内存中，任何文件和数据均不离开您的设备，彻底绝绝云端数据泄露风险。

支持断网离线使用或直接安装到电脑/手机桌面吗？

支持！平台已全方位支持 PWA（渐进式 Web 应用）标准。在 Chrome、Edge 或手机浏览器中，您可直接点击地址栏右侧的“安装应用”图标，将其以独立桌面软件的形式保存到设备桌面。在首次加载完成模型后，即使断开网络连接也能秒级离线启动和使用。

本地 OCR 文字识别使用的是什么模型？支持多页 PDF 吗？

引擎基于百度飞桨 PaddleOCR (PP-OCRv6) 轻量级深度学习离线模型，配合 ONNX Runtime Web 多线程 WASM 硬件加速，毫秒级本地完成文本检测与中英文识别。深度集成了 PDF.js，支持长篇 PDF 逐页高保真渲染识别或一键批量提取全文，并可直接导出为标准 Word (.docx)、对齐 Excel (.xlsx) 表格及纯文本 (.txt)。
